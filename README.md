# 양재일 개인 포트폴리오

금융 실무 37년 경험을 인공지능 역량으로 확장하는 과정을 기록한 GitHub Pages 기반 개인 포트폴리오입니다.

- 공개 주소: https://hopeon365.github.io
- 연락처: hopeon36588@gmail.com · [GitHub](https://github.com/hopeon365)
- 템플릿: [Start Bootstrap Resume](https://startbootstrap.com/theme/resume) (MIT License)를 참고하여 한국어 콘텐츠와 프로젝트 섹션을 추가
- 사용 기술: HTML5, CSS3, JavaScript, Bootstrap 5, Font Awesome

## 구성

| 섹션 | 내용 |
| --- | --- |
| 소개 | 진로 전환 배경과 목표 |
| 경력 | 사단법인 희망도레미 행정실장(2026.02~현재), 자영업자 재무애로 컨설팅 1년, 기업애로 경영컨설팅 5년, 은행 37년(최종 지점장) |
| 학력 | 서울사이버대학교 인공지능학과, 세무회계과 학사, 문학과 학사 |
| 역량 | 개발 도구 및 금융·재무 업무 역량 |
| 프로젝트 | 금융·신용 데이터 분석, 자영업자 재무 분석, 부동산 데이터 분석 (Colab 노트북·코드 링크) |
| 자격 | 전산세무 1급 등 5종 |

## 폴더 구조

```
index.html          # 단일 페이지
css/styles.css      # 사용자 정의 스타일
js/scripts.js       # 스크롤 스파이, 모바일 메뉴
assets/img/         # 프로필 사진, 파비콘
```

## 로컬에서 보기

`index.html` 파일을 브라우저로 열면 됩니다.

## 배포

GitHub 저장소 **Settings → Pages → Branch: `main` / `(root)`** 를 선택하고 저장하면 자동 배포됩니다.
